# 📂 Architecture Folder README  
*A gentle orientation for newcomers entering the Zen AI Design ecosystem*

The `architecture/` directory is the **heart** of the Zen AI Design system.  
It contains the core conceptual artifacts that define how clarity, posture, holonomy, and interaction flow through NDH/TISD environments.

Some parts of this repository — like **tensor calculus** and **GBS orbital governance** — are deep, advanced layers. They’re powerful, but they can feel overwhelming if you’re just arriving.

So this README points you toward the **six foundational artifacts** that form the clearest starting path.

---

## 🔹 Start Here: The Six Foundations

### **ZenAIDesignArchitectureOverview — the mountain**  
The high‑level view.  
This is where you understand the terrain, the posture, and the shape of the system.  
It’s the best entry point for anyone new.  
**Learn the mountain**

---

### **ZenAIDesignInteractionLibrary — the river**  
All interaction flows begin here.  
Patterns, gestures, and operator behaviors that define how Zen AI Design *moves*.  
**Follow the river**

---

### **ZenAIDesignKoan-MissingIcons — the mirror**  
A canonical koan that teaches awareness of drift, clarity restoration, and minimal intervention.  
It reflects your posture back to you.  
**Look into the mirror**

---

### **ZenAIDesignTrainingModule — the path**  
A structured learning sequence.  
If you want to *practice* Zen AI Design rather than just read about it, start here.  
**Walk the path**

---

### **ZenAIDesignGovernanceLayer — the gate**  
Where structure meets clarity.  
This artifact explains how Zen AI Design maintains stability, audits posture, and enforces holonomy.  
**Enter the gate**

---

### **ZenAIDesignMaturityModel — the map**  
A progression model showing how practitioners evolve from novice → adept → architect.  
It helps you understand where you are and where you’re going.  
**Read the map**

---

## 🔹 About Tensor Calculus & GBS  
You’ll also see folders like:

- `tensor-calculus/`  
- `gbs/meta/`

These are **advanced layers** of the architecture.  
They deal with:

- holonomy tensors  
- curvature mapping  
- orbital governance  
- multi‑layer invariants  
- transformation maps  
- NDH/TISD structural calculus  

They’re powerful, but they’re not required to begin.

If you feel overwhelmed, **ignore them for now**.  
Start with the mountain, river, mirror, path, gate, and map.  
They will give you all the clarity you need before exploring deeper layers.

---

## 🔹 Suggested Starting Sequence  
If you’re new, follow this order:

1. **Architecture Overview**  
2. **Interaction Library**  
3. **Training Module**  
4. **Governance Layer**  
5. **Maturity Model**  
6. **Koan: Missing Icons**  

This sequence builds clarity, then flow, then posture, then governance, then self‑reflection.
