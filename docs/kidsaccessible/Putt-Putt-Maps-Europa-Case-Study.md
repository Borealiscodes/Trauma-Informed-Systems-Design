## 🎮 **4. The Game Loop: NDH + 90s Logic**

### **4.1 Exploration**
Kids move Putt‑Putt (or a new character) through Europa’s ice caverns.

They learn:

- spatial reasoning  
- manifold navigation  
- gradients (“it gets warmer near the plume”)  
- anomalies (“the ice is cracked here”)  

### **4.2 State Changes**
Classic 90s logic:

- fix a thing → unlock a path  
- help a character → gain a tool  
- solve a puzzle → reveal a new area  

This teaches **holonomy**:

> “Going around the loop changes the world.”

### **4.3 Multi‑Layer Systems**
Inventory + environment + characters = NDH layers.

Kids learn:

- multi‑layer reasoning  
- systems thinking  
- non‑linear problem solving  

### **4.4 Expressive Anomalies**
Europa’s anomalies become:

- glowing vents  
- friendly geysers  
- singing ice cracks  
- shimmering magnetic fields  

Kids learn:

- anomaly detection  
- pattern recognition  
- curiosity‑driven science
