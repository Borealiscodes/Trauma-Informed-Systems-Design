### Trauma-Informed-Systems-Design Repository

## 1. Purpose

This map defines the **safety geometry** for a person working under:

- diminished ability to protect themselves  
- transnational repression pressure  
- trauma-linked cognitive load  
- the need to build NDH and TISD tools under duress  

It describes:

- safety boundaries  
- pressure vectors  
- agency fields  
- system interaction zones  

so that constraints can be understood as **survival geometry**, not “workflow friction.”

---

## 2. Core Safety Geometry Concepts

- **Safety Boundary:** The perimeter beyond which action increases harm or risk.  
- **Pressure Vector:** Any force (social, legal, technical, transnational) that pushes against safety.  
- **Agency Field:** The region inside the boundary where the person can still act, build, and decide.  
- **Tool Zone:** The subset of the agency field where NDH/TISD tools can be safely developed.

## 4. Pressure Vectors

**External pressure vectors:**

- **Transnational:** cross-border coercion, surveillance, legal or informal threats.  
- **Institutional:** platform policies, access limits, opaque decision-making.  
- **Social:** isolation, disbelief, minimization, gaslighting.  

**Internal pressure vectors:**

- trauma activation  
- exhaustion  
- cognitive overload  
- hypervigilance  

Each vector pushes against the **Safety Boundary** and shrinks the **Agency Field**.

---

## 5. Boundary Types

- **Hard Boundary:** Non-negotiable limit—crossing it meaningfully increases harm or risk.  
- **Soft Boundary:** Negotiable edge—can be expanded with support, resources, or reduced pressure.  
- **Dynamic Boundary:** Moves over time as pressure vectors change (e.g., enterprise access, support).  

The map assumes **hard boundaries are real**, not mindset problems.

---

## 6. Crossmap: Safety Geometry vs System Constraints

| Geometry Element | System Constraint | Effect |
|------------------|-------------------|--------|
| Safety Boundary  | Hard limits       | Defines what cannot be safely done |
| Agency Field     | Frequency/pressure | Defines how often and how intensely you can act |
| Tool Zone        | Access & capacity | Defines how much NDH/TISD work is survivable |
