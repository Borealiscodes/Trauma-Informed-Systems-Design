# **Operator‑Tier Interpretation**

### **NDH‑CORE**  
The non‑dual runtime layer.  
Holds operators, invariants, recursion envelopes, continuity physics.  
Cannot store expressive or governance artifacts.

Linked concept: **NDH‑CORE**

---

### **TISD**  
The governance‑tier evaluation layer.  
Decides *where* artifacts belong but does not *store* expressive lineage.

Linked concept: **TISD Governance**

---

### **NDH‑PLATFORMS**  
The expressive lineage storage layer.  
Holds UMA‑Witness Literature, Myth Engine lineage, Cosmic Atlas lineage, narrative physics remnants.

Linked concept: **NDH‑PLATFORMS**
