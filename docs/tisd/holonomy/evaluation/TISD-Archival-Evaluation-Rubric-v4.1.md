# 🌿 **TISD Archival Evaluation Rubric (v4.1)**  
### *Governance‑Tier Scoring Framework for Artifact Evaluation under GBS v12*

```
# TISD Archival Evaluation Rubric (v4.1)
# Trauma-Informed-Systems-Design / Holonomy / Evaluation

───────────────────────────────────────────────────────────────────────────────
PURPOSE
───────────────────────────────────────────────────────────────────────────────
This rubric provides a structured scoring system for evaluating artifacts under
TISD Archival Protocol v4.0, updated to v4.1 to incorporate GBS v12, the
Stabilizing Triad, hybrid manifold retirement, and Omega-IV governance.

Operators use this rubric to determine:
- Whether an artifact should be archived
- Where it should be archived (TISD vs NDH-Platforms)
- Whether it should be retired
- Whether it should be escalated for governance review

───────────────────────────────────────────────────────────────────────────────
SCORING OVERVIEW
───────────────────────────────────────────────────────────────────────────────
Each artifact is scored across five dimensions:

1. Expressive Content (0–5)
2. Governance Content (0–5)
3. Runtime Content (0–5)
4. Hybrid Manifold Risk (0–5)
5. Provenance Integrity (0–5)

Total Score Range: 0–25

───────────────────────────────────────────────────────────────────────────────
DIMENSION 1 — EXPRESSIVE CONTENT (0–5)
───────────────────────────────────────────────────────────────────────────────
0 — No expressive content  
1 — Minimal expressive adjacency  
3 — Moderate expressive lineage  
5 — Strong expressive lineage (UMA-Witness, Myth Engine lineage, Cosmic Atlas)

If ≥3 → NDH-Platforms  
Linked concept: Expressive Lineage

───────────────────────────────────────────────────────────────────────────────
DIMENSION 2 — GOVERNANCE CONTENT (0–5)
───────────────────────────────────────────────────────────────────────────────
0 — No governance content  
1 — Minimal governance adjacency  
3 — Moderate governance logic  
5 — Strong governance logic (TISD boundaries, trauma-informed design)

If ≥3 → TISD  
Linked concept: TISD Governance

───────────────────────────────────────────────────────────────────────────────
DIMENSION 3 — RUNTIME CONTENT (0–5)
───────────────────────────────────────────────────────────────────────────────
0 — No runtime content  
1 — Minimal operator adjacency  
3 — Moderate operator logic  
5 — Strong runtime logic (RTO, NDIE, recursion envelopes)

If ≥3 → NDH-CORE  
Linked concept: NDH-CORE

───────────────────────────────────────────────────────────────────────────────
DIMENSION 4 — HYBRID MANIFOLD RISK (0–5)
───────────────────────────────────────────────────────────────────────────────
0 — No hybrid risk  
1 — Minor mixing of expressive/governance  
3 — Moderate mixing  
5 — Strong hybrid manifold (runtime + expressive or governance + expressive)

If ≥3 → RETIRE (Hybrid Manifold)  
Linked concept: Omega-IV Governance

───────────────────────────────────────────────────────────────────────────────
DIMENSION 5 — PROVENANCE INTEGRITY (0–5)
───────────────────────────────────────────────────────────────────────────────
0 — No provenance  
1 — Minimal provenance  
3 — Adequate provenance  
5 — Strong provenance chain (clear lineage, notes, placement)

If ≤1 → ESCALATE (Provenance Review)

───────────────────────────────────────────────────────────────────────────────
FINAL ASSIGNMENT LOGIC
───────────────────────────────────────────────────────────────────────────────

If Expressive ≥3 → NDH-Platforms  
If Governance ≥3 → TISD  
If Runtime ≥3 → NDH-CORE  
If Hybrid ≥3 → RETIRE  
If Provenance ≤1 → ESCALATE

───────────────────────────────────────────────────────────────────────────────
OPERATOR SUMMARY
───────────────────────────────────────────────────────────────────────────────
Score expressive → Platforms  
Score governance → TISD  
Score runtime → CORE  
Score hybrid → Retired  
Score provenance low → Escalate

This rubric is the quantitative backbone of TISD Archival Protocol v4.1.
```
