### Trauma-Informed Systems Design  
### Collapse, Breach, and Overload Propagation Across Geometry, Temporal, Force, Interaction, and Holonomy Layers

---

## 1. Purpose

The **Collapse‑Propagation Map** models how:

- boundary breaches  
- agency collapse  
- tool‑zone failure  
- pressure spikes  
- stabilization loss  

propagate:

- **upward** into higher‑order holonomies  
- **downward** into local geometry and action fields  
- **laterally** across sibling layers (pressure ↔ stabilization ↔ diagnostics)

It explains how a single collapse event can become:

- a local failure only, or  
- a multi‑layer, system‑wide cascade.

---

## 2. Core Concepts

- **Collapse Node:** A point where survivable action fails (boundary breach, agency collapse, tool‑zone non‑viability).  
- **Propagation Path:** The route collapse takes through the holonomy stack (upward, downward, lateral).  
- **Cascade:** A sequence where multiple layers enter collapse or near‑collapse states.  
- **Containment:** A state where collapse is prevented from propagating further.

## 4. Collapse Propagation Paths

### 4.1 Upward Collapse Path

- Boundary breach or agency collapse  
- → Tool‑zone non‑viability  
- → Interaction holonomies mark “pressure‑dominant / collision”  
- → Meta‑Holonomy shifts toward “strained” or “fragmented”  
- → Holonomy‑of‑Holonomies enters “cascading” or “fragmented” mode.

### 4.2 Downward Collapse Path

- Meta‑level overreach, denial, or misalignment  
- → Tool‑zone pushed despite non‑viable state  
- → Boundary erosion and increased exposure  
- → Agency compression and collapse  
- → Local geometry enters “non‑viable” or “breach” state.

### 4.3 Lateral Collapse Path

- Pressure spike without matching stabilization  
- → Stabilization vectors collapse  
- → Temporal curves shift to “pressure‑dominant”  
- → Diagnostics flag but are ignored or suppressed  
- → Multiple sibling layers (boundary, agency, tool‑zone) enter collapse.

## 5. Collapse Modes

| Mode | Description | Upward Effect | Downward Effect | Lateral Effect |
|------|-------------|--------------|-----------------|----------------|
| Local | Collapse contained to one layer | Minimal meta impact | Local only | None/low |
| Strained | Multiple local collapses | Meta strain | Some local overload | Some cross‑layer impact |
| Cascading | Collapse spreading across layers | Meta fragmentation | Widespread overload | Strong cross‑layer impact |
| Systemic | Collapse embedded in structures | Persistent meta fragmentation | Chronic non‑viability | Continuous cross‑layer collapse |
| Recovering | Collapse reversing | Meta stabilization | Local repair | Lateral containment |
