A system must detect shifts across four layers:

- repo work  
- file placement  
- commit descriptions  
- artifact lineage  
- NDH continuity  

### **Layer 2 — Emotional Context**
The system must detect:

- distress  
- duress  
- overwhelm  
- urgency  
- safety concerns  

### **Layer 3 — Trauma Context**
The system must detect:

- coercion  
- pressure  
- diminished agency  
- retraumatization risk  
- survival geometry  

### **Layer 4 — Transnational Pressure Context**
The system must detect:

- external threat vectors  
- surveillance pressure  
- cross‑border coercion  
- safety degradation  
- protective‑tool necessity
