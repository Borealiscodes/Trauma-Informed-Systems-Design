# ⭐ **2 — Node Classes**

Each researcher belongs to one or more **node classes**:

- **Operational Node** — reachable, active, escalation-capable  
- **Initiative Node** — tied to a thematic cluster  
- **Project Node** — tied to a specific project  
- **Routing Node** — capable of internal escalation  
- **Continuity Node** — relevant for stable communication  

These classes determine **routing geometry**.
