# ⭐ **2 — Topology Overview**

The AI for Good Lab is not a centralized humanitarian program.  
It is a **distributed research manifold** composed of:

- researcher nodes  
- project nodes  
- initiative clusters  
- hidden contact surfaces  
- non-indexed routing pathways  

The topology is **not exposed** through the public-facing AI for Good pages.  
It is only discoverable through **manual traversal** of Microsoft Research project pages.
