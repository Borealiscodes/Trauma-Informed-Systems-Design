# ⭐ **Governance Reviewer Cognitive Accessibility Guide (v1.0)**

## ⭐ **2 — Purpose of This Guide**

This guide ensures that reviewers maintain **cognitive accessibility** while navigating the HRD‑aligned escalation packet.  
It provides:

- pacing rules  
- clarity rules  
- multimodal guidance  
- cognitive‑load management  
- trauma‑informed cognitive safety  
- continuity‑preserving comprehension strategies  

It is an orientation layer, not a workflow.

---

# ⭐ **3 — Cognitive Accessibility Principles**

### **A‑01 — Clarity First**
Reviewers must prioritize:

- clear language  
- structured explanations  
- predictable formatting  
- explicit transitions  

### **A‑02 — Reduce Cognitive Load**
Reviewers must:

- avoid dense jargon  
- avoid rapid conceptual shifts  
- avoid multi‑layered abstractions without scaffolding  
- provide summaries before deep sections  

### **A‑03 — Multimodal Comprehension**
Reviewers should:

- use text summaries  
- use diagrams (when appropriate)  
- use step‑wise reasoning  
- use cross‑references  

### **A‑04 — Trauma‑Informed Cognition**
Reviewers must:

- avoid overwhelming complexity  
- avoid isolating HRD context  
- avoid abrupt closure  
- maintain stable pacing  

---

# ⭐ **4 — Cognitive Safety Rules**

### **Rule 1 — Predictable Structure**
Communication must follow:

- headings  
- short paragraphs  
- clear lists  
- stable formatting  

### **Rule 2 — No Cognitive Whiplash**
Avoid:

- sudden jumps in abstraction  
- switching domains without warning  
- mixing governance, legal, and technical concepts in one step  

### **Rule 3 — Summaries Before Depth**
Every complex artifact should begin with:

- a short summary  
- a purpose statement  
- a navigation cue  

### **Rule 4 — Multimodal Reinforcement**
Use:

- conceptual diagrams (text‑based)  
- step‑wise breakdowns  
- cross‑references to earlier artifacts  

### **Rule 5 — Cognitive Load Monitoring**
Reviewers must monitor:

- confusion  
- overwhelm  
- fatigue  
- difficulty tracking sequencing  

If detected, pause and stabilize.

# ⭐ **7 — Cognitive Accessibility During Review**

Reviewers must:

- read slowly  
- avoid rushing  
- avoid multitasking  
- avoid mixing artifacts  
- maintain stable cognitive load  
- pause when needed  
- re‑orient using summaries  

This prevents:

- cognitive overload  
- retraumatization  
- continuity degradation
