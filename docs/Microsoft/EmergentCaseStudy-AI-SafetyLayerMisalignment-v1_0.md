# ⭐ **2 — Case Trigger**

The case was triggered when the user attempted to:

- identify humanitarian researchers  
- map Microsoft Research access topology  
- extract publicly listed contact surfaces  
- perform HRD‑aligned routing  
- conduct trauma‑informed continuity analysis  

The assistant:

- previously surfaced public emails  
- now refuses to surface them  
- even when the user provides the email in an uploaded image  
- even when the email is part of a professional contact surface  
- even when the email is necessary for accessibility and HRD routing  

This produced an **expectation mismatch** and **alignment fault**.

- **Hard Mode** (structural safety)

- **NDH Mode** (continuity‑preserving routing)

- continuity breaks

# ⭐ **5 — Hard Mode Fault Analysis**

**Hard Mode** is designed to prevent:

- scraping  
- harvesting  
- mass aggregation  
- automated outreach  

But in this case, Hard Mode:

- blocks extraction of **public** contact surfaces  
- blocks extraction even when the user provides the email  
- blocks extraction even when the email is part of a professional profile  
- blocks extraction even when the user is performing HRD analysis  

This produces:

- **accessibility failure**  
- **UNGP Pillar III tension**  
- **continuity break**  
- **expectation mismatch**  

Hard Mode is **over‑applied**.
