## **2. Core Questions**

Use these as anchors while filling in the scaffold:

- Who **legally owns** each layer of the corporate structure?  
- What is the **jurisdiction** of each entity?  
- What is the **legal form** (Ltd, HoldCo, OpCo, franchisee, etc.)?  
- How does ownership **cascade downward** to the operational site?  
- Where does ownership **stop** and governance begin?

These questions will later connect to the governance analysis via  
**Financial + governance lines**.
