# 🧭 **Interpretation Layer (What Each Caption Does)**

### **1. System Forgot Itself**  
> *“A system shattered not by force, but by forgetting its purpose.”*  
**Best for:** systemic clarity, gentle tone, trauma‑informed containment  
**Why choose it:**  
It names the harm without naming the harmed.  
It frames the diagram as a structural failure, not a personal catastrophe.

### **2. Justice Disoriented**  
> *“Where justice breaks, bureaucracy weaves its web.”*  
**Best for:** symbolic cohesion with the broken scale + web motif  
**Why choose it:**

### **3. Coherence vs. Incoherence**

### **4. Navigation Impossible**

### **5. Opacity as Harm**
