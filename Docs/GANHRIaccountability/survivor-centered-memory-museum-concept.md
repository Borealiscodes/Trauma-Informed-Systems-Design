# **Survivor‑Centered Memory Museum Concept**  
## **A Global, Decentralized, Trauma‑Informed Space for Truth, Memory, and Collective Witnessing**

### **Executive Summary**

When institutions collapse — courts, NHRIs, civil society, media, and international bodies — survivors lose not only protection and remedy, but also **public memory**.

Memory becomes fragmented.  
Evidence disappears.  
Narratives are suppressed.  
History is distorted.

A **Survivor‑Centered Memory Museum (SCMM)** restores:

- narrative agency,  
- public memory,  
- collective witnessing,  
- cultural recognition,  
- and global solidarity.

This concept outlines a **transnational, decentralized, trauma‑informed museum ecosystem** designed to preserve suppressed evidence, amplify survivor testimony, and create public awareness through art, archives, digital exhibits, and community spaces.

---

# ⭐ **1. Why a Survivor‑Centered Memory Museum Is Necessary**

Montgomery (2022) shows that multiagency cover‑ups produce:

- narrative suppression,  
- institutional betrayal,  
- evidence disappearance,  
- delegitimization of victims.

Your filings document:

- torture,  
- enforced disappearance,  
- refoulement,  
- judicial obstruction,  
- civil society complicity,  
- media silence,  
- international non‑responsiveness.

These conditions create a **memory vacuum** — a space where truth is erased.

A memory museum restores:

- truth,  
- dignity,  
- visibility,  
- and collective understanding.

# **2. Core Principles of the Memory Museum**

### **2.1 Survivor Ownership**
Survivors define:

- what is displayed,  
- how it is contextualized,  
- what is archived,  
- and what is withheld.

### **2.2 Decentralization**
The museum is not a single building — it is a **global network**.

### **2.3 Trauma‑Informed Curation**
Every exhibit follows trauma‑informed design.

### **2.4 Accessibility**
Multiple formats:

- physical,  
- digital,  
- artistic,  
- narrative,  
- anonymous.

### **2.5 Global Solidarity**
The museum connects communities across borders.
