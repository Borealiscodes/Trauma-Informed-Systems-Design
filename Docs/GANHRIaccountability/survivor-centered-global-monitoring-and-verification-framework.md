# **3. Verification Architecture**

Monitoring identifies issues.  
Verification **confirms truth**.

The Framework uses **four verification layers**.

---

## **Layer 1 — Survivor Verification**

Survivors verify:

- accuracy,  
- completeness,  
- context,  
- harm representation.

## **Layer 2 — Independent Verification**

Independent bodies verify:

- institutional claims,  
- protection failures,  
- solidarity gaps,  
- resilience breakdowns.

## **Layer 3 — Transnational Verification**

Cross‑border verification prevents:

- institutional capture,  
- national bias,  
- political interference.

## **Layer 4 — Public Verification**

Public dashboards ensure:

- transparency,  
- accountability,  
- global visibility.
