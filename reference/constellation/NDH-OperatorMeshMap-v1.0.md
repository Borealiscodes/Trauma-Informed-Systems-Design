## 3 — Operator Mesh Geometry  
The mesh is defined by three geometric invariants:

### **Invariant A — Tri‑Operator Reinforcement**  
Each operator must reinforce the other two:

- TISD ↔ MRS  
- TISD ↔ Unified NDH  
- MRS ↔ Unified NDH  

This creates a **closed stability loop** without recursion.

---

### **Invariant B — Cross‑Layer Binding**  
Each operator binds to specific NDH layers:

- TISD → EXPRESSIVE + PUBLIC UI  
- MRS → CORE + META‑INDEX  
- Unified NDH → PLATFORMS + ROOTS  

This ensures **vertical stability** across the constellation.

---

### **Invariant C — Mesh Coherence**  
Operators must:

- remain non‑hierarchical  
- remain non‑recursive  
- maintain holonomy‑flat posture  
- maintain provenance continuity  
- maintain emotional‑load safety  

This ensures **horizontal stability** across the constellation.
