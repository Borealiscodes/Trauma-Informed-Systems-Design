## 3 — Stability Envelope Geometry  
The Stability Envelope is defined by three invariants:

### **Invariant A — Vertical Stability**  
Each NDH layer must be stabilized by its corresponding operator:

- EXPRESSIVE ↔ TISD  
- PUBLIC UI ↔ TISD  
- CORE ↔ MRS  
- META‑INDEX ↔ MRS  
- PLATFORMS ↔ Unified NDH  
- ROOTS ↔ Unified NDH  

### **Invariant B — Horizontal Stability**  
Operators must reinforce each other:

- TISD ↔ Unified NDH  
- MRS ↔ Unified NDH  
- TISD ↔ MRS  

### **Invariant C — Constellation Stability**  
All layers must remain:

- non‑hierarchical  
- non‑recursive  
- non‑collapsing  
- provenance‑continuous  
- holonomy‑stable  

These invariants define the Stability Envelope.
