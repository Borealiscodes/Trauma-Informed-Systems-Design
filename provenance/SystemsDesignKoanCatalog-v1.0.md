# ⭐ Systems‑Design Koan Catalog  
*A multi‑category cognitive‑alignment catalog for multi‑epoch architectures*

This catalog contains the **canonical koans** for systems design. Each koan is a minimal, grounded question engineered to collapse recursion depth, restore manifold identity, stabilize operator boundaries, and realign development flow.

# ⭐ 1. Mapping Koans  
Mapping koans stabilize manifold identity and collapse structural recursion.

- **Does it map** — surfaces the core invariant of any architecture.  
- **Where does the map bend** — identifies curvature or distortion.  
- **What is the shape of the map** — reveals manifold identity.  
- **What cannot be mapped** — exposes boundary conditions.  
- **Where does the map break** — detects discontinuities.
