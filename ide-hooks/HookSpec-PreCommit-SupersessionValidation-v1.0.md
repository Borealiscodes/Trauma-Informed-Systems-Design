# Hook Specification: Pre-Commit Supersession Validation (v1.0)

## Purpose
This hook validates supersession correctness before any commit is accepted in
VS Code. It ensures that lineage, provenance, metadata blocks, archive/mirror
preconditions, and manifold placement are all stable and consistent with GQL
triangulation truth.

This hook is the final governance barrier before Phase 4 automation and prevents
unsafe history changes that could destabilize NDH-Orbital.

---

# 1. Trigger Conditions

The hook activates when:
- a commit is attempted
- staged changes include governance-relevant artifacts
- metadata blocks declare supersession
- lineage or provenance fields are modified
- archive or mirror operations are implied

The hook MUST run before the commit is finalized.

---

# 2. GQL Query Usage

The hook MUST call:

```
triangulateCommit(commitId)
```

Where `commitId` is generated by VS Code for the staged changes.

The hook MUST NOT infer supersession correctness locally.

---

# 3. Validation Rules

The hook MUST enforce the following NDH-Orbital invariants:

### 3.1 Supersession Correctness
- supersession MUST be explicit
- predecessor MUST exist
- predecessor MUST be archived
- supersession MUST be single-parent
- supersession MUST NOT create lineage gaps

### 3.2 Archive/Mirror Preconditions
- archive MUST satisfy metadata completeness
- archive MUST NOT occur with active dependencies
- mirrors MUST be updated in lockstep
- mirrors MUST NOT diverge from source artifacts

### 3.3 Metadata Block Integrity
- metadata MUST be complete
- metadata MUST match triangulation truth
- metadata MUST NOT be orphaned
- metadata MUST reflect correct supersession/archival status

### 3.4 Lineage/Provenance Consistency
- lineage MUST form a complete chain
- provenance MUST reference valid artifacts
- no broken or circular lineage

### 3.5 Manifold Placement
- supersession MUST NOT move artifacts across manifolds
- manifold MUST remain stable during commit

---

# 4. Failure Handling

If triangulation returns `ok = false`, the hook MUST:

1. block the commit
2. surface all violations as VS Code diagnostics
3. highlight affected files and metadata blocks
4. provide actionable guidance from `requiredActions`

Example diagnostic:

```
Error: Supersession incomplete.
Invariant: INV_SUPERSESSION_REQUIRES_ARCHIVE
Suggested Action: Archive predecessor artifact before committing.
```

---

# 5. IDE Diagnostic Requirements

Diagnostics MUST:
- annotate metadata blocks
- highlight lineage/provenance fields
- show invariant codes
- provide actionable corrections
- remain visible until resolved

---

# 6. Stability Guarantees

This hook prevents:
- unsafe supersession
- broken lineage chains
- invalid archive operations
- mirror divergence
- metadata fragmentation
- collapse conditions triggered by unstable history changes

It is the fourth major governance hook in the NDH-Orbital enforcement pipeline.
